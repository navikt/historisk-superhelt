# Triage-etiketter

Bruk etiketten i høyre kolonne når en skill viser til en triage-rolle.

| Rolle | Etikett i GitHub | Betydning |
|-------|-----------------|-----------|
| `needs-triage` | `needs-triage` | Må vurderes av vedlikeholder |
| `needs-info` | `needs-info` | Venter på mer informasjon fra innmelder |
| `ready-for-agent` | `ready-for-agent` | Ferdig spesifisert, klar for en agent |
| `ready-for-human` | `ready-for-human` | Krever implementasjon av et menneske |
| `wontfix` | `wontfix` | Skal ikke gjennomføres |
